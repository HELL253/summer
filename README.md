# 嵌入式目标测量
本项目包含目标测量系统和功耗监测系统，主要由K230单目视觉和STM32F103C8T6主模块、串口屏、INA226模块等构成，完成了对指定目标物的远距离非接触式测量。系统通过K230摄像头捕捉目标图像，利用内置的图像处理算法识别不同几何图形，并基于建立的单目测距模型，精确计算目标物距离与边长或直径。功耗监测系统利用INA226对系统供电电流与功率进行实时采样，经主控分析后显示在触摸屏上。图像处理算法包括灰度化、二值化与轮廓识别，主控配合串口屏实现交互控制与结果输出。经测试系统可在1秒内完成图像处理与距离计算，误差范围控制在标准内；具备实时功耗监测与较强的稳定性，适用于非接触测量需求的工业与智能视觉应用场景
